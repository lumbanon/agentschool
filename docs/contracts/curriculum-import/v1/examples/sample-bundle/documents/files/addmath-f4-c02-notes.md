# Quadratic equations: revision notes (example document)

## Factorisation

Write $ax^2 + bx + c = 0$ as a product of two linear factors, then use the
zero-product property: if $pq = 0$ then $p = 0$ or $q = 0$.

## Checking roots

Substitute each root back into the original equation. Both sides must be equal.

## Common mistakes

- Sign errors: $(x + 4) = 0$ gives $x = -4$, not $x = 4$.
- Losing a root: $x^2 = 9$ has two roots, $x = 3$ and $x = -3$.
